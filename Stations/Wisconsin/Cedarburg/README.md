# Cedarburg, Wisconsin - Milwaukee Road passenger depot

Project folder made 24 Nov 2026. Status: drawings filed, no model yet (TDQ-339, TDQ-643).

The depot is single-storey with two gabled pavilions on the street side, wide hipped eaves, and an open shelter (pavilion) at one end. It is drawn by the C.M.&St.P. Bridge and Building Department.

Drawings (private, in copyright) are in Research Library / RSW / Stations / Wisconsin / Cedarburg / MPL drawings (private - in copyright):
- 01 Floor plan (B-8, 16-1009-1).jpg
- 02 Elevations (B-9, 16-1009-2).jpg
- 03 Sections (B-10, 16-1009-3).jpg
- 04 Sections (B-11, 16-1009-4).jpg
- 05 Sections (B-12, 16-1009-5).jpg

The copies are only about 745 px wide. That is enough to read the shape but too small to read the figures. Re-save sheets 01 and 02 at full size (MPL link, full/4000) before modelling.
