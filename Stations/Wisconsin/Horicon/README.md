# Horicon, Wis. passenger station

Milwaukee Road (C.M.&St.P.) depot. Folder made 24 Nov 2026.
Source drawing: Album sheet 86, built 1914 (drawn Apr 10 1917). Private reference (in copyright): Research Library / RSW / Stations / Standard depots / Album of Depot Plans 1919.
About 50 miles from Madison.

## From the drawing
110 ft overall: 86 ft 6 building + 24 ft pavilion; freight room 20 ft 6 x 18; general waiting, ticket office, smoking room; enlarged from a 42 ft old building; lap siding, shingle hip roofs.
