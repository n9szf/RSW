# Walworth, Wis. 24 x 48 ft freight house

Milwaukee Road (C.M.&St.P.) depot. Folder made 24 Nov 2026.
Source drawing: Album sheet 125, drawing B-755, Sept 16 1910 (also used at Mobridge, S.D. 1912). Private reference (in copyright): Research Library / RSW / Stations / Standard depots / Album of Depot Plans 1919.
About 60 miles from Madison.

## From the drawing
24 x 48 ft, floor 3 ft 6 above rail on posts, 6 ft platform track side; 14 ft walls, 1/3 pitch shingle roof, drop siding, class B rolling doors.
