# Portage, Wisconsin - Milwaukee Road passenger depot

Project folder made 24 Nov 2026. Status: drawings filed, no model yet (TDQ-339, TDQ-644).

There are 21 MPL sheets covering several eras: the depot and hotel building remodeling (B-2336, B-2337), new shelter sheds for the eastbound main track, the big alteration and remodeling of the passenger depot (B-5618 to B-5660, with a canopy), and floor plans (16-947).
