# Muscoda, Wis. passenger station

Milwaukee Road (C.M.&St.P.) depot. Folder made 24 Nov 2026.
Source drawing: Album sheet 118, drawing B-3261, July 26 1927. Private reference (in copyright): Research Library / RSW / Stations / Standard depots / Album of Depot Plans 1919.
About 55 miles from Madison.

## From the drawing
78 ft 6 in x about 24 ft; waiting 20 x 23, ticket office 10 x 13 with bay, freight and baggage 32 ft 3 x 39?; high platforms; brick, hipped shingle roof.
