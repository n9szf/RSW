# Madison West (West Washington Ave) depot - HAND-BUILT

Do not overwrite with the station generator. Main file: OpenSCAD/Madison_West_Station.scad
(Madison_West_Station_G / _O / _HO.scad set the scale). Modelled as of 1940 with the Feb 1941
waiting room inside, from the 1903-04 MPL drawings, the National Register nomination, Tom's
photos of 9 Oct 2026 and the six 1941 album photos (reference / Stations / Wisconsin /
Madison West (West Washington) / Photos (private)).

Print parts: print_parts.json (MR Print Files); PRINTER / SHOW / TILE / LIST in the .scad.
Mortar is blue for now (MORTAR in the .scad) so the joints stand out; "#8A4A32" is the real colour.
Renders: Blender/render_station.py (aurora job madison_west_check_1125, 25 Nov).
Open TDQs: 658 (HO test print + build guide), 659 (arches and brickwork check).
