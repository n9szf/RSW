# Minneapolis, Minnesota - Milwaukee Road Depot (1899)

Status 24 Nov 2026: drawings and history are filed, no model yet (TDQ-219, TDQ-646).

This is the 1899 Charles S. Frost depot: pink granite and yellow brick, a roughly 140 ft tower with a Giralda-style top (lost in 1941), a 625 ft train shed, and a baggage and express building. Tom 10/8: model the 1899 version with the tall tower.

Files in Research Library / RSW / Stations / Minnesota / Minneapolis:
- History - Milwaukee Road Depot (Minnesota Historical Society 10-26-21).pdf
- MPL drawings 1899 (private - in copyright): 20 sheets, still named default (n).jpg, about 1200 x 800 px. That is readable for the shape, but the dimensions need full-size copies (links in TDQ-219).

Plan: name the 20 sheets, then make a 2D footprint and elevations. Because it is so large, decide on a scale and a footprint (headhouse only, or with the train shed) before going to 3D.
