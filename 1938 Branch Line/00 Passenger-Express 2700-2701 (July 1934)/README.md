# Passenger & Express 2700-2701 (July 1934)

TDQ-456 (25 Oct 2026). Source: 'Hiawatha - First of the Speedliners' (Milwaukee Shops Inc 1993), roster p. 117.

- Same body as 2702-2707 (Dec 1934). The book says the cars differed only in the trucks; the later cars also got a portable conductor's table.
- 5 ft 6 in wheelbase Bettendorf trucks, drawn here as a plain 4-wheel truck (print the caboose truck kit to run it).
- Kit files: Kit / G scale 1-29, O scale 1-48, HO scale 1-87 (OpenSCAD). STL sets come from tools/export_release.sh.
