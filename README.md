# Rib Side Works (RSW)

Milwaukee Road models in OpenSCAD for model railroaders: passenger cars, locomotives, cabooses and freight equipment, stations and trucks. Most are drawn for G scale (1:29), with O (1:48) and HO (1:87) versions.

Models are free for personal use. For commercial use, contact the owner.

## What is here
- **Passenger cars**: one folder per train group (for example `1939 Hiawatha`, `1911-1931 Heavyweights`). Each car has a `Kit` folder with a stand-alone OpenSCAD file for each scale and an illustrated **How to build** PDF.
- **Freight**, **Locomotives**, **Stations**, **Trucks**: OpenSCAD files and build books for those groups.
- **MR Print Files**: a small program that makes print files from the kits.
- **libraries**: BOSL2, used by some locomotive files (passenger car kits do not need it).
- **3D models (.glb)**: on the [3d-models release](../../releases/tag/3d-models), and in the online 3D viewer (GitHub Pages for this repository).

See [BUILD_INSTRUCTIONS.md](BUILD_INSTRUCTIONS.md). Requires OpenSCAD 2025 or newer.

Updated every Friday night. Some models are still being checked against prototype records; check each model's notes before relying on a detail.
